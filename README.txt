Районы Москвы — учебный HTML-сайт

Откройте index.html в браузере. Все остальные страницы доступны из общего меню.
Страницы, файл script.js и папка images должны оставаться рядом в папке moscow_site_pages.

Список страниц:
index.html — главная
districts.html — районы
transport.html — транспорт
parks.html — парки и архитектура
table.html — таблица районов
forms.html — формы
dom.html — считывание паспортных данных из DOM
translit.html — изменение записи по клику
algorithm.html — алгоритм № 1007
photo.html — большое изображение
script.js — JavaScript
images/ — локальные изображения

Сайт написан без CSS. Формы отправляются на внешний демонстрационный сервис httpbin.org.
Для задания DOM следует самостоятельно сделать скриншот консоли браузера.
